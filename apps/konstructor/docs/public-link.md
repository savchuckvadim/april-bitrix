# Публичный конструктор по ссылке

Для сотрудников, которые смотрят правила формирования комплектов. Адрес
`/p/<token>` открывает сборку без Битрикса, пользователя и настроек: КП и документы
не формируются, сборка не сохраняется, описание комплекта скачать можно. Ссылки
создают и отзывают в админке: **Konstructor → Публичные ссылки**. Бэк —
`back/apps/konstructor/src/modules/public-link` (там README с ручками и правилами
доступа).

## Как устроено

Экраны шагов одни и те же, у поверхностей разные стор, гейт и адреса.

| | Фрейм сделки | Публичная версия |
| --- | --- | --- |
| Гейт и провайдеры | `modules/app` (`App`, `Providers`) | `modules/public-app` (`PublicApp`, `PublicProviders`) |
| Стор | `modules/app/model/store.ts` | `modules/public-app/model/public-store.ts` |
| Общее ядро стора | `modules/app/model/core-reducers.ts` | то же |
| Адреса и шаги | `BITRIX_FLOW_SURFACE` | `publicFlowSurface(token)` |
| Шаг «Цены» | `widgets/deal-price-table` | `widgets/price-table` |
| Описание комплекта | слушатель в `start-store-listeners`, файл в хранилище портала | слушатель в `public-listeners`, файл потоком |
| Настройка вида | браузер и сервер | только браузер |
| Запросы | сгенерированный клиент | свой прокси `app/api/public/[token]`, адрес бэка браузеру не нужен |

## Правило: Битрикса в зоне публичных экранов нет

`modules/public-app/__tests__/no-bitrix.test.ts` обходит граф импортов от входов
публичной версии и падает, если что-то дотягивается до `@workspace/bitrix`, `bx`,
`pbx`, `pbx-data`, `nest-api`, `@bitrix/*` или читает срез, которого нет в публичном
сторе. Сообщение теста показывает всю цепочку импортов.

Что из этого следует при правках:

- Хуки стора нижние слои берут из `@/modules/app`. В этом барреле только хуки и
  типы; всё остальное из app-слоя импортируется по прямому пути.
- Экраны шагов и то, что они импортируют, не читают `state.app`, `state.portal`,
  `state.deal` и прочие срезы фрейма. Нужно что-то про сделку — это слот, как в
  `widgets/deal-price-table`, или слушатель в слое приложения.
- Новый срез, нужный обеим поверхностям, добавляется в `core-reducers.ts`.

## Отзыв

Отозванная и истёкшая ссылки дают 410. Страница проверяет ссылку при открытии, при
возврате на вкладку и раз в 5 минут, пока вкладка видна. На 410 стор обнуляется и
показывается экран «Ссылка больше не действует». Уже скачанные файлы отозвать нельзя.

Отзыв закрывает страницу и её ручки. Фрейм берёт тот же каталог через
`POST konstructor/init/data`, и эта ручка отдаёт его только сессии своего портала:
при старте фрейм молча обменивает свой AUTH_ID Битрикса на токен
(`modules/app/lib/portal-session`, `POST auth/portal-session`), входа для
пользователя нет. Закрыто, когда у бэка `PORTAL_SESSION_GUARD_MODE=enforce`.

## Локальная проверка

Dev-прокси ходит в `KONSTRUCTOR_API_URL`, а без него — в
`NEXT_PUBLIC_KONSTRUCTOR_API_URL`. Чтобы открыть ссылку с локального бэка, задайте в
`apps/konstructor/.env` `KONSTRUCTOR_API_URL=http://localhost:3007/` и перезапустите
dev-сервер.

Вне фрейма сессии нет, и dev ходит в бэк без токена. С бэком в режиме `enforce`
каталог тогда не откроется: dev против такого бэка — только во фрейме тестового
портала, локальный бэк по умолчанию в `report`.
