# Конструктор — руководство пользователя

Как пользоваться новым конструктором Гарант (Next-версия). Из сделки Bitrix
конструктор открывается сам и ведёт на нужный экран: новая сделка — на старт
(Избранное · Акции · Создать), сделка с вариантами КП — на выбор варианта,
сохранённая сделка — на экран документов. Сборка идёт шагами: Параметры →
Комплект → Цены (**/prices**) → Документ.

## Вспоминание сделки

Открыл приложение из сделки → конструктор сам находит сохранённое предложение
(слепок) этой сделки и показывает его на экране товаров **с теми же ценами,
что были при сохранении** — даже если прайсы с тех пор изменились.

- Жёлтый баннер «Сделка восстановлена с замечаниями» — что-то из старой записи
  не удалось сопоставить с текущими справочниками (например, снятый с продажи
  комплект). Строки при этом на месте, цены сохранены.
- Слепка нет → чистый конструктор: собери главный товар через панель добавления.
- Пересчитать вспомненные цены по текущим прайсам — кнопка ⟳ на блоке набора
  (автоматически цены никогда не пересчитываются).

## Шапка экрана

| Контрол | Что делает |
|---|---|
| **Текущий комплект** | Имя комплекта главного товара (с цветом/иконкой комплекта) |
| Комплект / Кол-во доступов (ОД) / Тип договора | Меняют ГЛАВНЫЙ товар; недоступные комбинации скрываются, несовместимые поставка/договор сбрасываются на первые допустимые |
| **X-ОД** | В селекте ОД пункт «X-ОД — своё количество…»: любое число одновременных доступов (1–999). Цена считается интерполяцией между соседними видами поставки (и всегда правится вручную); количество попадает в слепок и в договорные поля |
| Регион | Пересчитывает цены всех наборов по региональному прайсу |
| Поставщик | Налог 5%: цены пересчитываются ×1.05 / ÷1.05. **Лицензионные договоры налогом не облагаются** — их цены не меняются |

## Карточка товара

- **Имя** — карандаш или двойной клик: своё название (подчёркнуто пунктиром).
- **Строка рефов** «Вид поставки • Договор • мера» — как в старой версии; ⚙ раскрывает
  селекты **Комплект / ОД (с X-ОД) / Договор** — у КАЖДОГО Гаранта свои
  (в т.ч. у дополнительных — в старой версии так было нельзя).
- **Цена / Количество (или Аванс) / Скидка / Сумма** — правишь любое поле, остальные пересчитываются. Enter/уход из поля — применить, Esc — отменить. Кнопка ₽/% переключает режим скидки. Под полями — подсказки: цена «в месяц», мера («абон. 12 мес.»), сумма без скидки.
- **Количество едино для всего набора** — правка на любой строке применяется ко всем (кроме пакетов Академии «в часах»).
- **Иконка комплекта** — открывает наполнение строки.
- 🗑 — удалить строку (главный товар удалить нельзя; удаление последнего Гаранта удаляет весь набор).

### Сервисные строки

Сменить **консалтинг** или **пакет Академии**, убрать **СТАР** можно прямо
в карточке сервисной строки (селект/кнопка) — это правит наполнение ведущего
Гаранта, и набор пересобирается сам. LT-пакет производен от веса выбранных
LT-сервисов — состав меняется в наполнении строки.

Строка **«LT доп.»** — дополнительный пакет Legal Tech: переименовать (своё
название уйдёт в документы) и убрать можно в карточке, состав пакета —
в наполнении.

## Наполнение (состав комплекта)

Редактор наполнения открывается для **любой** garant-строки любого набора:
инфоблоки, ЭР и пакеты ЭР, Legal Tech, консалтинг, СТАР, академия.

- Сервисные строки (LT-пакет, консалтинг, СТАР, академия) появляются в наборе
  автоматически из наполнения.
- Тумблер **«По правилам / Без правил»**: по правилам — автокоррекции и запреты
  (мин. 5 LT у Офиса, развал пакета ЭР и т.д.); без правил — только подсветка
  расхождений (вес и пр.), ничего не навязывается.
- Строка «Вес: N / эталон M» — контроль веса комплекта.
- **Legal Tech — дополнительные пакеты**: кнопка «Пакет» добавляет ещё один
  платный пакет LT с любым набором сервисов; пакет каталога подбирается по
  суммарному весу (2 / 5 / 10, средний пакет весом 4 — только сервисному
  отделу, без правил — всем). Жёлтый вес — пакет не собран, строки в наборе
  у него нет. Название правится кликом по имени пакета.
- **Искра** считается по вхождениям: в наполнении и в каждом доп. пакете —
  по 20 запросов в день; документ пишет «Искра (N запросов в день)».
- **СТАР** в документах раскрывается подсервисами (калькулятор сроков, поиск
  поставщиков, НМЦК и др.).
- Кнопка **«Описание комплекта»** в итоге шага — DOCX с описаниями выбранных
  блоков по группам (тексты — из портала).

## Наборы

- **Основные** — то, что продаём (главный + дополнительные Гаранты + сервисы).
- **Для сравнения** — до 7 альтернативных наборов для КП (в сделку Bitrix не уходят).
- **Объединить/Разъединить** — свернуть набор в одну строку-итог (имена через «+», суммы сложены). В свёрнутом виде редактируется только Количество; карандаш ✎ открывает полный доступ к строкам и итогу.
- Сводка набора: «Всего наименований K на сумму X ₽, в т.ч. НДС 5% — Y ₽» (НДС — только при поставщике с налогом).

## Сохранение предложения

Кнопка **«Сохранить предложение»** в шапке пишет текущее состояние (все наборы,
цены, наполнение) в слепок сделки. «Сохранено ✓» появляется по факту ответа
сервера. При следующем открытии сделки конструктор вспомнит именно это.
Старые слепки при пересохранении переводятся в новый формат (v2) — прочитать
их сможет только новая версия конструктора.

## Документы

Шаг «Документ»: **КП** (Word-шаблон, получатель и счёт; при нескольких
вариантах комплекта — один файл со всеми участниками), **Договор**
(поля сделки, спецификация, реквизиты из вкладки «Реквизиты»), **Отчёт о
поставке** (поля формы, контакты, заявка RPA). Если на портале включены
«3 КП для торгов» — на экране КП появляется карточка настроек поставщиков.

## Сервисный отдел

У сервисного отдела в шапке цен и документов — переключатель периода
**«Текущий / Следующий»**: текущий — слепок сделки, следующий — слепок
продления (смарт «Предложение сервисного отдела»); сохранение и отправка
пишут в выбранный период.

## Что пока в разработке

Смоук на тестовом портале во фрейме, событие «документ сформирован» для
отдела продаж, облегчённая поставка сервисного отдела.
